# Controlel Vision

## Motto

Understand the building before controlling it.


## Mission

Controlel is an adaptive building regulation platform.

Its goal is not only to control heating devices,
but to understand building behaviour and optimize
comfort, efficiency and reliability.


## Core Principles

1. Safety first

The system must always have a safe fallback.


2. Explainability

Every important decision must be understandable.


3. Modularity

Hardware integrations must not affect core logic.


4. Evidence based optimization

No automatic optimization without measurable proof.


5. Human control

The user always remains in control.


6. Progressive intelligence

Start simple.
Measure.
Learn.
Improve.
